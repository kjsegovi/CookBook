DM Sans and CookBook Serif are web subsets covering Latin, Latin Extended,
common punctuation, currency, fractions, and arrows. Other scripts use the
system fallback fonts in the stylesheet.

CookBook Serif is a renamed subset of Lora, respecting Lora's Reserved Font
Name. Original copyright and license metadata are retained in the font.
See DM-Sans-LICENSE.txt and Lora-LICENSE.txt for attribution and licenses.
